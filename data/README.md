# JalSetu Purulia Demonstration Dataset

## Important Notice
> **WARNING: All data in this directory is SIMULATED.**  
> The assets, observations, and maintenance records contained here are hypothetical illustrative examples created solely to demonstrate the software workflow.  
> **They are NOT real field measurements, official government records, or verified village statistics.**  
> Do not cite these numbers as evidence of district-wide water savings, groundwater table improvement, or completed interventions.

## File Contents
- `sample-assets.json`: Three hypothetical structures:
  1. *Demo Site A (School Rooftop RWH)* — 200 m² catchment, 10,000 L storage tank.
  2. *Demo Site B (Community Pond)* — Silted earthen pond with irregular geometry.
  3. *Demo Site C (Farm Pond)* — Lined agricultural storage pond.
- `sample-observations.csv`: 40 simulated water depth and rainfall observations spanning June to September 2024 to illustrate seasonal monsoon patterns and time-series graphing.

## Loading Demonstration Data
In the JalSetu Purulia web app, the demonstration dataset is loaded by default on first run, or you can click **"Reset to Demo Data"** in the sidebar at any time.
